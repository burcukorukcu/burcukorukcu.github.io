# burcukorukcu.github.io

Personal portfolio of Burcu Körükcü, Senior Data Engineer in Berlin, served by GitHub Pages at <https://burcukorukcu.github.io/>.

A single static page (`index.html`) built with Tailwind CSS (Play CDN) and Lucide icons. There is no build step: edit `index.html`, push to `master`, and GitHub Pages redeploys.

Sections: About, Toolkit & Skills (including AI & Agentic Development), Work Experience, Writing (latest Medium posts via RSS), Education & Certifications.

## Preview locally

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
